# How Microchips Are Made — three.js + HyperFrames + Kokoro

A 4 min 40 s explainer on semiconductor manufacturing, rebuilt from scratch:

- **Narration:** an original script (`script/narration.json`), voiced locally with
  [Kokoro-82M](https://huggingface.co/hexgrad/Kokoro-82M) (voice `af_heart`), with word-level timings.
- **3D:** every shot is procedural [three.js](https://threejs.org) (no stock footage), drawn by one
  renderer from timeline time (`assets/js/`).
- **Compositing and render:** [HyperFrames](https://hyperframes.heygen.com). The three.js stage is
  one sub-composition, and the chapter titles, counters and the 8-step recipe bar are GSAP sub-compositions.
- **Music:** a quiet ambient bed generated on-device with MusicGen-small (`script/make_music.py`), if present.

The output is `renders/how-microchips-are-made.mp4`. `transcript.json` has the same
word-level format as the original video's transcript at the repo root.

## Chapters

| # | Chapter | What you see |
|---|---|---|
| — | Hook | X-ray phone with 62 chips lighting up, a human hair vs. a 57 nm transistor pitch, a wafer printed with light |
| 01 | Inside the chip | Lid off a desktop CPU, the 24-core die, a fall through 17 copper layers, FinFETs |
| 02 | Eighty layers | 80 patterned layers stacking up; ~940 steps, 3 months; one speck of dust |
| 03 | One layer, eight steps | Cross-section: deposit oxide → resist → expose → develop → etch → strip → copper → polish |
| 04 | Six families | The recipe as a loop of colour-coded tools, lapped 80 times |
| 05 | Inside the fab | 435 tools, the amber lithography bay, a wafer pod riding the overhead rail |
| 06 | Lithography | Scanner cutaway with 4× reduction, die-by-die exposure of 230 chips, 80 masks |
| 07 | Add, remove, modify | Deposition, plasma etch, CMP, ion implant (1 in 10,000), anneal |
| 08 | Clean and inspect | Spin rinse and nitrogen dry, electron-beam inspection finding a defect |
| 09 | Before the fab | Quartz → silicon → single crystal → notched wafers; $100 → ~$100,000 |
| 10 | After the fab | Test and binning, laser dicing, flip onto the package, heat spreader |
| — | Outro | Back to the phone in your pocket |

The six machine families keep one colour each for the whole film: lithography amber, deposition teal,
etch/polish coral, implant violet, clean sky blue, inspection lime.

## Rebuild

```bash
# voice + timings (Python 3.12 venv with kokoro>=0.9.4, misaki[en], soundfile, en_core_web_sm)
python script/make_vo.py
ffmpeg -i assets/vo/vo_raw.wav -af loudnorm=I=-16:TP=-1.5:LRA=11 -ar 48000 assets/vo/vo.wav

# optional music bed (torch + transformers)
python script/make_music.py && bash script/loop_music.sh

# scene hosts from the timings, then preview / check / render
node script/build.mjs
npx hyperframes preview
npx hyperframes check
npx hyperframes render -o renders/how-microchips-are-made.mp4
```

Every 3D cue is tied to a narrated word (`World.cue("fab", "fifty")`), so editing the script and
re-running the three steps above re-times the whole film.

## Layout

```
index.html                 root composition (generated by script/build.mjs)
compositions/stage.html    the three.js canvas; World.render(t) on every hf-seek
compositions/ch-*.html     per-chapter GSAP overlays (tags, counters, recipe bar, end card)
assets/js/core.js          renderer, cue lookup, 3D-anchored labels, shared materials
assets/js/shots-*.js       the shots, chapter by chapter
assets/timing.js           Kokoro word timings (generated)
script/                    narration, TTS, music, index builder
```
